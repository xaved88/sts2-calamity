# Calamity — a Slay the Spire 2 difficulty mod

Adds **Ascension 11 (Calamity)**:

- **Trials:** a Trial floor right after each act's Ancient. The party votes on one of three trials (nods to the nine
  Slay the Spire 1 bosses) for this act's boss; in Act 3 you vote one *out* and the other two go to the two bosses.
- **Calamities:** two Calamity floors per act (before the treasure and before the boss). Each offers players + 1
  **hardships** (negative relics); everyone takes one, and the leftover is discarded. 48 hardships across a General pool
  and per-act pools.
- **The Pact:** in co-op, a fallen player is still revived after the fight, but someone pays: the dead player grasps
  an ally, or an ally volunteers, and they take an Eternal **Unholy Pact** curse that hurts more with every revive.

Design and balance live in [design/hardships.md](design/hardships.md); rules for new content are in
[CONVENTIONS.md](CONVENTIONS.md). Built on
[BaseLib](https://github.com/Alchyr/BaseLib-StS2) from [Alchyr's mod template](https://github.com/Alchyr/ModTemplate-StS2/wiki),
against STS2 **v0.107.1**.

## Build, install, share

Requires Docker only (the .NET 9 SDK and the art tools run in containers).

```powershell
./build.ps1             # render art, build DLL + PCK, copy Calamity and BaseLib into <game>/mods
./build.ps1 -NoDeploy   # build only (output in build/mods)
./build.ps1 -SkipArt    # reuse existing PNGs
./package.ps1           # build/release/Calamity-<version>.zip for friends + build/workshop/Calamity for the Workshop
```

- **Zip:** friends extract it and double-click `Install-Calamity.bat`, which copies the mods into their game folder.
  `tools/share/INSTALL.md` (inside the zip) has them run `unlock all` in the dev console to unlock everything up to
  A11 on their fresh modded profile.
- **Steam Workshop:** use Mega Crit's [sts2-mod-uploader](https://github.com/megacrit/sts2-mod-uploader):
  `ModUploader.exe upload -w build\workshop\Calamity`. `workshop.json` defaults to `friends_only`; add BaseLib's
  Workshop ID to `dependencies` first. Keep the `mod_id.txt` it writes so later uploads update the same item.

## Testing

- Dev console (`` ` ``) → `unlock ascensions` sets every character (and multiplayer) to A11 on the current profile.
- `relic add CALAMITY-<NAME>` grants a hardship, e.g. `relic add CALAMITY-LUMPY_COT`.
- Logs: `%APPDATA%\SlayTheSpire2\logs\godot.log` (search `[Calamity]`).
- Modded play uses a separate profile (`steam/<id>/modded/`).

## Layout

| Path | What |
| --- | --- |
| `CalamityCode/CalamityAscension.cs` | Ascension levels the mod adds (A11). |
| `CalamityCode/CalamityRules.cs` | `CustomSingletonModel` that rewrites freshly generated maps at A11+. |
| `CalamityCode/Map/` | `[CustomEnum]` point types and `CalamityActMap` (inserts the Trial and Calamity rows 1:1, no RNG). |
| `CalamityCode/CalamityRoom.cs` | What a calamity chest offers: tier odds, General + act pools, Crushing guarantee. |
| `CalamityCode/Hardships/` | `HardshipRelic`/`HardshipPower` bases, the pool, hardship cards, and each pool's hardships. |
| `CalamityCode/Pact/` | Unholy Pact card, the revive patch + synced choice, the prompt UI, the volunteer message. |
| `CalamityCode/Trials/` | Trial event, the nine trial powers, Trial Writ relic, map badges. |
| `CalamityCode/Patches/` | Harmony patches: ascension cap, map routing/icons, calamity treasure room. |
| `Calamity/localization/eng/` | All text, merged natively by the game from the PCK. |
| `Calamity/images/` | Rendered art (generated by `tools/art`; don't hand-edit). |
| `tools/art/` | `make_placeholders.py` writes SVGs (never overwrites), `render.ps1` renders, `preview.py` contact sheet. |
| `reference/` | Decompiled `sts2.dll` and BaseLib (gitignored; local reading only). |

### Adding a hardship

1. Subclass `EnemyPowerHardship<T>` / `PlayerPowerHardship<T>` (combat effects, logic in the power) or `HardshipRelic`
   (out of combat) in the right pool folder; set `Tier` and (for act pools) `Act`. See [CONVENTIONS.md](CONVENTIONS.md).
2. Add text to `Calamity/localization/eng/relics.json` (and `powers.json`); keys are prefixed `CALAMITY-`. The build
   fails if any text is missing.
3. Add an SVG (or a drawing to `make_placeholders.py`) named after the class in snake_case.

### Known gaps

- Calamity and Trial floors record in run history as "?" floors.
- The game-over screen's "next ascension unlocked" message still stops at A10 (the unlock itself works).
- Incompatible with other mods that raise the ascension cap (e.g. Ascension+).
- Not yet verified in real co-op: the Pact choice, Trial voting, the fifth calamity slot for 4 players, Fogbound
  Lantern's card backs, and Trial of the Slime's summon.
